# 🚀 AI Project Setup Guide (Windows + UV + VS Code)

---

# Step 1: Create the Project Folder

```cmd
mkdir 1-BASICS-OF-LANGCHAIN
cd 1-BASICS-OF-LANGCHAIN
```

Verify your location:

```cmd
cd
```

Expected:

```text
F:\AI learnings 2026\langchain-Proejcts\1-BASICS-OF-LANGCHAIN
```

---

# Step 2: Initialize the UV Project

```cmd
uv init
```

This creates:

```
pyproject.toml
README.md
main.py
.python-version
```

---

# Step 3: Create the Virtual Environment

Use Python 3.12.

```cmd
uv venv --python 3.12
```

If your PC blocks UV-managed Python  use:

```cmd
uv venv --python "C:\Users\ADMIN\AppData\Local\Programs\Python\Python312\python.exe"
```

---

# Step 4: Activate the Virtual Environment

```cmd
.venv\Scripts\activate
```

Expected:

```text
(.venv)
```

---

# Step 5: Verify the Environment

```cmd
python --version
```

Expected:

```text
Python 3.12.x
```

Check the interpreter:

```cmd
where python
```

Expected:

```text
...\1-BASICS-OF-LANGCHAIN\.venv\Scripts\python.exe
```

---
