The most important step before pushing to GitHub is **making sure `.gitignore` is correct**. Here's the exact workflow I use for every project.

---

# Step 1: Create `.gitignore` (First)

Before `git init`, create a file named:

```text
.gitignore
```

Example:

```gitignore
# Virtual Environment
.venv/

# Environment Variables
.env

# Python
__pycache__/
*.pyc

# VS Code
.vscode/

# Temporary Files
temp.pdf

# Jupyter
.ipynb_checkpoints/
```

---

# Step 2: Initialize Git

```bash
git init
```

---

# Step 3: Check What Git Sees (Very Important)

Run:

```bash
git status
```

### ❌ Bad

If you see:

```text
new file: .env
new file: .venv/...
```

**STOP.**

It means `.gitignore` isn't working correctly.

Fix `.gitignore` first.

---

### ✅ Good

You should see only project files like:

```text
new file: main.py
new file: README.md
new file: requirements.txt
new file: pyproject.toml
new file: research_papers/Attention.pdf
```

You should **NOT** see:

* `.env`
* `.venv`
* `__pycache__`

---

# Step 4: Add Files

```bash
git add .
```

---

# Step 5: Verify Again

Run:

```bash
git status
```

Make sure **`.env` is still not listed**.

---

# Step 6: Commit

```bash
git commit -m "Initial commit"
```

---

# Step 7: Rename Branch

```bash
git branch -M main
```

---

# Step 8: Create a GitHub Repository

On GitHub:

* New Repository
* Repository name
* **Don't** initialize with a README if your local project already has one.

---

# Step 9: Connect Local Repository

```bash
git remote add origin https://github.com/USERNAME/REPOSITORY.git
```

Check it:

```bash
git remote -v
```

You should see:

```text
origin https://github.com/USERNAME/REPOSITORY.git (fetch)
origin https://github.com/USERNAME/REPOSITORY.git (push)
```

---

# Step 10: Push

```bash
git push -u origin main
```

---

---

## 🚨 Golden Rule

Always run this **before `git add .`**:

```bash
git status
```

If you ever see:

```text
new file: .env
```

or

```text
new file: .venv
```

**Don't continue.**

Fix `.gitignore` first, then run `git status` again until those files no longer appear.

This simple habit will prevent almost all of the GitHub secret-scanning issues you encountered.
